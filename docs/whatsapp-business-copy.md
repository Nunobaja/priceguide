# Plantillas internas para WhatsApp Business

> **Uso interno de Precios Locales.** Textos listos para adaptar y entregar al dueño de un negocio. Sustituye únicamente los marcadores con información confirmada; no inventes servicios, zonas, precios, horarios ni condiciones.

## 1. Propósito

Estas plantillas ayudan al negocio a compartir desde WhatsApp Business su página individual de precios aproximados de Precios Locales. El cliente puede consultar una estimación inicial antes de pedir la confirmación del costo del servicio.

Esto no es analítica, panel de seguimiento, CRM ni captación de prospectos. El parámetro `source=whatsapp-business` solamente marca el origen dentro del mensaje de WhatsApp, el resumen copiado y el enlace copiado; no registra visitas ni crea perfiles de clientes.

## 2. Formato de la URL

La URL individual del negocio debe usar exactamente este formato:

```text
{baseUrl}?source=whatsapp-business
```

Estructura de ejemplo con marcador, sin datos de un negocio:

```text
{businessPageUrl}?source=whatsapp-business
```

En todas las plantillas, sustituye `{whatsappBusinessUrl}` por la URL completa de la página individual de Precios Locales con `?source=whatsapp-business`:

```text
{whatsappBusinessUrl} = {baseUrl}?source=whatsapp-business
```

## 6. Plantillas de respuestas rápidas

Configura un atajo breve para cada respuesta y adapta solamente los datos confirmados del negocio.

### Ver precios aproximados

Puedes consultar un rango aproximado según el servicio y sus detalles aquí: {whatsappBusinessUrl}

### Pedir datos para estimar

Para orientarte, compárteme el servicio que necesitas, tu zona y los detalles principales del trabajo.

### Explicar que es estimación

La guía muestra una estimación inicial. El costo definitivo depende de los detalles y, cuando corresponda, de una revisión del trabajo.

### Enviar link de guía

Aquí puedes seleccionar el servicio y consultar una estimación aproximada: {whatsappBusinessUrl}

### Pedir zona

¿En qué colonia, zona o código postal se realizaría el servicio?

### Pedir foto/video

¿Puedes enviarme una foto o video claro del área o equipo? Evita compartir documentos o datos personales que no sean necesarios.

### Confirmar visita

La visita queda confirmada para la fecha y hora acordadas. Si cambia algún detalle, avísanos con anticipación.

### No tengo precio exacto todavía

Todavía no tengo el costo definitivo. Primero necesito revisar los detalles y, si aplica, inspeccionar el trabajo.

## 8. Ejemplos por servicio

Usa estos ejemplos únicamente cuando el servicio esté confirmado para el negocio.

### Aire acondicionado

**Mensaje:** ¿Necesitas servicio de aire acondicionado? Selecciona el tipo de trabajo y consulta una estimación inicial aquí: {whatsappBusinessUrl}

**Recordatorio de lenguaje seguro:** Presenta el resultado como rango aproximado; el costo definitivo depende del equipo, su condición y la revisión necesaria.

### Plomería

**Mensaje:** Para tu servicio de plomería, revisa un precio aproximado según la zona y los detalles: {whatsappBusinessUrl}

**Recordatorio de lenguaje seguro:** No presentes la estimación como costo cerrado; primero confirma el tipo de problema, el acceso y el trabajo requerido.

### Electricidad

**Mensaje:** Consulta una estimación para el servicio eléctrico que necesitas y después compártenos los detalles: {whatsappBusinessUrl}

**Recordatorio de lenguaje seguro:** Usa lenguaje de estimación inicial; el costo definitivo requiere conocer las condiciones y el alcance del trabajo.

### Jardinería

**Mensaje:** Revisa un rango aproximado para tu servicio de jardinería según las opciones disponibles: {whatsappBusinessUrl}

**Recordatorio de lenguaje seguro:** Aclara que el monto puede cambiar según el área, las condiciones del lugar y las tareas solicitadas.

### Control de plagas

**Mensaje:** Selecciona el servicio de control de plagas y consulta un precio aproximado aquí: {whatsappBusinessUrl}

**Recordatorio de lenguaje seguro:** Indica que es una orientación inicial; el costo definitivo depende del tipo de atención, el espacio y los detalles confirmados.

## 9. Instrucciones para el dueño del negocio

- [ ] Pega `{whatsappBusinessUrl}` en la descripción del negocio, el mensaje de bienvenida, el mensaje de ausencia, las respuestas rápidas o los estados donde corresponda.
- [ ] Usa el enlace en una respuesta cuando el cliente pregunte cuánto podría costar un servicio y necesite una orientación inicial.
- [ ] Explica que el costo definitivo depende de la inspección, el alcance o los detalles cuando esa información sea necesaria para evaluar el trabajo.
- [ ] No prometas un costo definitivo antes de contar con la información suficiente o realizar la revisión necesaria.
- [ ] Si el número de WhatsApp no está confirmado, no publiques ni entregues un enlace de contacto. Confirma el número con el dueño y prueba el flujo antes de usar estas plantillas.

## 10. Checklist interno de entrega

- [ ] Confirmar la URL de la página individual del negocio.
- [ ] Confirmar que el parámetro sea exactamente `source=whatsapp-business`.
- [ ] Confirmar el estado del número de WhatsApp con el dueño.
- [ ] Confirmar que no se haya creado un enlace de WhatsApp roto.
- [ ] Confirmar que los textos no prometan precios definitivos exactos.
- [ ] Confirmar que los textos no mencionen clasificaciones, reseñas, descuentos ni presupuestos asegurados.
- [ ] Abrir `{whatsappBusinessUrl}` y comprobar que corresponde al negocio correcto.
- [ ] Probar el mensaje, el resumen copiado y el enlace copiado para comprobar que conservan el origen.
